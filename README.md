# Codex金手指

## 先把这段发给 Agent，安装交给它

在你的 Windows 电脑上，打开能联网、能操作本机文件的 Agent，把下面整段复制给它。下载、校验、解压和安装，让它来做。

```text
请帮我在这台 Windows 电脑上安装或升级「Codex金手指」（Golden Finger for Codex）。
项目：https://github.com/LeoSasion/golden-finger-for-codex

请先阅读这个项目最新版的 README 和 docs/LOCAL-GUIDE.md，再直接完成安装，不要只给我一份操作教程：
1. 从该项目官方 GitHub Releases 自动获取最新正式版的 Windows x64 完整 ZIP 和对应的 .sha256 文件，校验 SHA-256 后再解压。不要用源码 ZIP 代替发行包，也不要只拿单个 EXE。
2. 使用包内 bin/GoldenFingerSetup.exe 安装到 %LOCALAPPDATA%\GoldenFingerApp；如果已经安装，优先在原安装目录升级，保留设置和可回退版本。遇到运行中的旧窗口或连接器，先检查活动请求，不要直接强制结束。
3. 按当前 Codex 支持的官方插件安装方式接入完整插件，让 Skill 和 MCP 都可用；保留已有配置，不要覆盖其他插件，不要修改私有数据库或伪造安装缓存。
4. 核对窗口与连接器来自同一版本、同一构建。需要我打开独立窗口、点击插件安装入口或重启客户端时，再明确告诉我该做哪一步；不要擅自打断正在运行的任务。
5. 条件具备后，用无副作用的文字问询检查接入：确认这个聊天能收到金手指的回答。没有实际通过就如实报告，不要把“文件装好了”当成“已经接入成功”。

你可以直接完成上述下载、校验、安装和必要的受支持配置。最后告诉我安装版本、安装位置、启动入口和接入检查结果；需要我操作的部分集中说明。
```

发行包自带运行环境，**日常使用不用另装 Python**。Agent 会帮你找包；需要你亲自点击的客户端步骤，它会接着说明。详细操作见[本机安装指南](docs/LOCAL-GUIDE.md)。

## 少打几个“同意”，多干一点正事

Agent 写着写着，又问“要继续吗？”；切了几个项目，还得找这次确认到底是哪一条。Codex金手指就是给这些时刻准备的。

它把接入的确认、选择和命令请求放进一个独立窗口。看清是哪件事，点一下“同意”，Agent 收到答案接着干。你想逐条把关也行，想给熟悉的流程设个倒计时也行。

**你负责拿主意，重复敲“可以、继续、就这个”的活儿交给金手指。**

英文名：Golden Finger for Codex。给每一位 Yes工程师的一点小外挂。

## 它能帮你省下哪些事？

- **确认换个说法，也能接住。** “这样可以吗？”“还按这个方案走吗？”“是否不再提示？”——按完整语义处理，不靠几个固定关键词，也不要求原问题真的带布尔参数。
- **有选项，点同意就选第一项。** 0.4.0 会保留原文和原顺序；第一项有没有“推荐”都一样。窗口里能看到这次“同意”对应什么。
- **不想继续，随时表态。** 是/否问题点“拒绝”就是否；单选题点“拒绝”不会偷偷选第二项。还没决定就点“停止”，这次不作答，待批准的命令也不会启动。
- **把精确命令交给独立窗口。** 看清程序、参数和影响后，再让它执行；结果和日志会回到原来的 Agent 调用。运行中的命令还有单独的“终止”入口。
- **几个项目一起做，也能认清来源。** 每条请求都显示项目和任务，结果回到原来的 Agent 调用，帮你少点错一次。
- **需要时提醒，不用一直盯着。** 新请求提醒、浅色/深色主题、通知偏好和主动收起到托盘，让这个小窗口更顺手。

## 三个按钮，看一眼就会

| 眼前这件事 | 同意 | 拒绝 | 停止 |
| --- | --- | --- | --- |
| 是/否问询 | 回答“是”，保留原问题含义 | 回答“否” | 不作答 |
| 有选项的问询 | 选择原始第一项 | 不选择任何项 | 不作答 |
| 一次具体动作的授权 | 同意这一件事 | 不同意 | 取消等待 |
| 一条待执行的命令 | 批准后执行这条命令 | 不执行 | 取消等待，不执行 |

命令已经获批排队或运行时，“停止”会变成单独的“终止”操作。终止可以阻止后续执行，已经发生的修改不会自动撤销。

## 想自己点，还是让倒计时帮忙？

默认等待 **5 秒**，倒计时就在“同意”按钮里。到时仍待处理的请求会自动同意；如果是命令，它也会进入执行。

想逐条亲自确认，就把“自动审批等待”设为 **0** 并应用。想留更长时间核对，可以改成自己习惯的秒数。手动点击和自动同意会分别记录，自动回执不代表你亲自点过。

## 装好以后，怎么用？

1. 按 Agent 提供的启动入口，自己打开金手指窗口。
2. 在要使用的聊天里说：“使用 Codex金手指处理接下来的确认和单选问询。”首次会让你选择只用于本次、当前任务、当前项目，还是所有项目。
3. 新请求到了，先核对项目、问题和按钮对应的答案，再决定。

选使用范围，只是告诉 Agent 以后哪些问询送到这里，每件事仍有自己的请求卡。窗口没开时，它会让你选择打开窗口继续，或取消金手指作用域。

想确认有没有接上，点窗口里的“接入检查”。窗口能打开，只说明程序能运行；**当前聊天能发来请求、收到回执，才算这次接入跑通了。**

## 先说清楚，才用得放心

目前面向 **Windows x64 + 支持本地插件的 Codex 环境**。安装提示词适合有本机执行能力的 Agent，只有网页聊天权限的助手无法替你装本机软件。

金手指在 Agent 发问前接入普通确认和单选问询；已经弹出的宿主卡片、自由文本、多选和 Codex 原生权限审批，仍走各自流程。它不会替你绕过沙箱或其他审批要求。

命令会继承金手指窗口的运行权限。窗口关闭后，未完成的请求不会跨重启自动恢复或重放。更多细节见[安装与排障指南](docs/LOCAL-GUIDE.md)和[技术说明](docs/TECHNICAL-REFERENCE.md)。
